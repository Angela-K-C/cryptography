# Cryptography Labs

This repository contains my cryptography labs, assignments, and practical experiments as I learn about cryptography and computer security.

The idea is to get hands-on experience with the concepts we learn in class, understand how different cryptographic algorithms work, and explore how they are implemented using programming languages and security tools.

I'll be documenting the steps I take in each lab, including the code, commands, screenshots, challenges, and observations along the way.

## Labs

### 1. RSA Public-Key Encryption and Signature Lab

This lab focuses on understanding how RSA works and how it is used in public-key cryptography.

Some of the things I explored include:

- Calculating the RSA private key using Euler's totient function and modular inverses.
- Encrypting and decrypting messages using RSA.
- Generating and verifying digital signatures.
- Understanding how message hashing works with digital signatures.
- Examining X.509 certificates and manually verifying their signatures using OpenSSL.

**Tools used:** C, OpenSSL, Python, GCC and Ubuntu.

[Read the RSA Lab Report](reports/rsa.md)
